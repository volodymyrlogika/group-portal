### ⚙️ Підготовка та запуск

#### 1\. Віртуальне середовище

Створіть та активуйте віртуальне середовище для ізоляції залежностей проєкту.

  * **Створення:**
    ```bash
    python -m venv .venv
    ```
  * **Активація:**
      * **Windows:**
        ```bash
        .venv\Scripts\activate
        ```
      * **Linux/macOS:**
        ```bash
        source .venv/bin/activate
        ```

#### 2\. Встановлення залежностей

Встановіть усі необхідні бібліотеки з файлу `requirements.txt`:

```bash
pip install -r requirements.txt
```

#### 3\. Міграції бази даних

Застосуйте міграції для створення необхідних таблиць у базі даних:

```bash
python manage.py makemigrations
python manage.py migrate
```

#### 4\. Створення суперкористувача

Створіть адміністратора для доступу до панелі управління Django:

```bash
python manage.py createsuperuser
```

#### 5\. Запуск сервера у розробницькому режимі

Запустіть локальний сервер розробки, щоб перевірити роботу проєкту:

```bash
python manage.py runserver  
```

#### 6\. Запуск проєкту на асинхронному сервері (опціонально)

Для запуску проєкту на асинхронному сервері, такому як Uvicorn, використовуйте наступні команди:
Спочатку зберемо статичні файли:

```bash
python manage.py collectstatic --noinput
```
Потім запустимо сервер Uvicorn:
```bash
uvicorn group_portal.asgi:application --host  127.0.0.1 --port 8000
```
#### 7\. Доступ до проєкту
Відкрийте веб-браузер і перейдіть за адресою
```http://127.0.0.1:8000```
 щоб побачити працюючий проєкт.
